# Wickfleet UI v0.2.0

The FreqUI fork for Wickfleet. Pair it with Wickfleet hub v0.2.0, which serves
the data for the new pages.

## New

| Page | What |
|---|---|
| Compare | pick 2 or more bots and a range, the hub replays each over the same window. Profit, drawdown, Sharpe, Sortino, profit factor, win rate, trades, average hold, walk-forward windows, Monte Carlo drawdown and the verdict side by side, with the return curves overlaid. On a phone one card per bot |
| Risk | capital at stake against the wallets, open trades per bot, exposure per coin and per pair, drawdown now against the worst so far, each open trade's stop distance and pairs that several bots trade |
| Navigation | Fleet, Bots, Compare and Risk show only when a Wickfleet hub answers. Without a hub the UI is stock FreqUI |

Viewers and demo visitors see no amounts on either page. The hub removes them
before they reach the browser, the UI only hides the empty columns.
